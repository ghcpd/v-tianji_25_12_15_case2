### Key Features Implemented
- **Transaction Management**: Add, view, and delete income/expense transactions with categories (Food, Transport, Entertainment, Salary, Bills, Other)
- **Data Persistence**: Uses localStorage to save transactions between sessions
- **Summary Dashboard**: Displays total income, expenses, balance, and current month figures
- **Data Visualization**: Pie chart for expense categories and bar chart for monthly spending trends using Recharts
- **Responsive UI**: Modern, clean design with Tailwind CSS classes (though not fully installed, basic styling applied)

### Testing Coverage
- **Unit Tests**: 
  - AddTransactionForm component: Form rendering, submission, and reset functionality
  - Summary component: Correct calculation of totals and monthly figures
- **E2E Tests**: Full user flow of adding a transaction and verifying summary updates
- **Test Frameworks**: Vitest for unit tests, Playwright for E2E tests

### Commands Used
1. `npm create vite@latest . -- --template react-ts` - Initialize React project
2. `npm install recharts` - Install charting library
3. `npm install --save-dev vitest @testing-library/react @testing-library/jest-dom @testing-library/user-event jsdom @vitest/coverage-v8 @playwright/test` - Install testing dependencies
4. `npx playwright install` - Install Playwright browsers
5. `npm run test` - Run unit tests
6. `npm run dev` - Start development server
7. `npm run test:e2e` - Run E2E tests
