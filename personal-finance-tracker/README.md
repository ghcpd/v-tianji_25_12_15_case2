# Personal Finance Tracker

Local frontend-only demo app built with React, Vite, Tailwind CSS.

Commands (Windows):

- Install: npm install
- Dev server: npm run dev
- Run unit tests: npm test
- Run E2E tests: npx playwright test (or npm run e2e)

Project includes Vitest unit tests and Playwright E2E tests. Playwright is configured to start the dev server automatically.

Deliverables:
- App source in src/
- Unit tests under src/**/__tests__ and tests/setup.ts
- E2E tests under tests/e2e

Notes:
- Tests should run with Node >= 18. LocalStorage is used for persistence.
